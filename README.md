# Практичне заняття: Створення простого веб-сайту (HTML/CSS)

**Виконав:** Нікіта

## 📌 Опис проєкту
Цей проєкт — мій невеликий сайт-візитка, створений в рамках практичного заняття з основ програмування. Головна мета роботи: закріпити навички семантичної розмітки та стилізації за допомогою базового HTML та CSS.

## ✅ Що було реалізовано
1. **Базова структура:** Створено семантичний каркас сайту (`<header>`, `<main>`, `<section>`, `<footer>`).
2. **Розмітка контенту:** Додано заголовки, параграфи, маркований список навичок та зображення.
3. **Стилізація (CSS):** Підключено зовнішній файл `style.css`. Налаштовано кольори, відступи та шрифти.
4. **Робота з блоками:** Використано Flexbox для розташування тексту та фото.
5. **Адаптивність:** Додано `@media` для мобільних екранів.
6. **Навігація:** Меню з ефектами при наведенні та виділенням активної сторінки.
7. **Валідація:** Код перевірено в W3C Validator.

## 🚀 Як запустити локально
1. Відкрийте `index.html` у браузері або запустіть простий HTTP-сервер у папці проєкту.

Приклад (PowerShell):
```powershell
Set-Location 'c:\Users\strey\Desktop\oos\student-portfolio'
Start-Process index.html
```

Або (Python):
```bash
python -m http.server 8000
# потім відкрити http://localhost:8000
```
